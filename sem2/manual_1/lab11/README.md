## Постановка задачи
Написать программу, в которой создаются динамические структуры и  выполнить их обработку в соответствии со своим вариантом.
Для каждого вариант разработать следующие функции:
Создание списка.
Добавление элемента в список (в соответствии со своим вариантом).
Удаление элемента из списка (в соответствии со своим вариантом).
Печать списка.
Запись списка в файл.
Уничтожение списка.
Восстановление списка из файла.

## Анализ задачи
Рассмотрим реализацию структуры двунаправленного списка. Оставшиеся структуры получим путем её изменения.
1. Метод pushBack должен принимать на вход данные. Создается новый узел, в него записываются исходные данные. Для нового узла в качестве указателя на предыдущий элемент ставиться ссылка на текущий хвост, а для хвоста указываем новый узел в качестве следующего. Затем перезаписываем хвост, присваивая ему значение нового узла. Также следует рассмотреть случай, при котором размер списка равен нулю, так как в таком случае мы не сможем обращаться к полям хвоста. В этом случае перезапишем голову и хвост списка новым узлом. В конце обоих случаев увеличим размер списка на единицу.
2. Метод pushFront аналогичен методу pushBack, за исключением того, что разворачивается порядок.
3. Для метода popBack запоминаем указатель на последний удаляемый элемент. Затем перезаписываем хвост своим предшествующим элементом. Далее проверяем: если хвост != nullptr, то указываем в качестве следующего за ним элемента nullptr. В ином случае лист оказывается пустой, перезаписываем голову. Далее в любом случае освобождаем память и уменьшаем размер. Также нужно обработать граничный случай, когда размер списка уже ноль — в таком случае выходим из метода ничего не делая.
4. Метод popFront аналогичен popBack
5. Метод insert принимает на вход значение, которое мы хотим добавить и индекс этого значения в массиве. Создаем новый узел с входными данными. Если индекс равен нулю — вызываем pushFront, если равен размеру массива — вызываем pushBack. Далее следует проверить, лежит ли индекс на интервале (0; size), если нет — индекс невалиден. Далее задаем node = head, и в цикле перезаписываем node = node→next idx раз — так мы найдем узел, перед которым мы должны вставить данные. Далее для предшествующего node узла в поле next записываем указатель нашего нового узла, затем для нового узла в качестве prev указываем это узел. Затем для node указываем в качестве предыдущего значения новый узел, а для нового узла — в качестве следующего указываем node. Увеличиваем размер на единицу.
6. Метод remove принимает в качестве аргумента индекс удаляемого элемента. Проверяем, лежит ли он на полуинтервале [0, size). Если idx == 0, то вызываем popFront, если idx == size — 1 — вызываем popBack. В иных случаях аналогично методу insert ищем узел с нужным индексом. Задаем node->next->prev = node->prev и node->prev->next = node→next, удаляем искомый узел и уменьшаем размер.
7. Метод get ищет элемент с нужным индексом тем же способом, что используются в remove и insert и возвращает его.
8. Метод find идет по узлам с головы до тех пор, пока не встретит nullptr. На каждом шаге проверяется, равно ли значение в узле искомому и счетчик i увеличивается на единицу. Таким образом i — индекс искомого элемента.
9. Метод print аналогично методу remove идет по всем элементам списка и выводит их значения в поток.

0. Функция clear аналогично методам remove и print перебирает все элементы и удаляет их. Затем значениям head, tail присваевается nullptr, а размер становиться равен единице.
Для однонаправленного списка удаляется поле prev из узла, и соответственно вся работа с ним тоже. Отдельные изменения:
1. В методе popBack при размере равном одному, удаляем область памяти, лежащей по head, приравниваем концы списка к nullptr и обнуляем размер. В ином случае, начиная с head, перебираем узлы до тех пор, пока следующим узлом нашего списка не будет tail. Затем для найденного узла указываем next как nullptr и удаляем tail.
2. В методе remove так же не доходим на единицу до искомого узла, чтобы не потерять доступ (у нас нету prev, все пропущенные узлы теряются).
Очередь реализуем на основе односвязного списка. Оставляем методы pushBack, pushFront, insert, print, clear и добавляем peek — получение текущего head.
Стек реализуем также на основе односвязного списка. Оставляем функции pushFront (для простоты назовем её push), popFront (pop), peek, print, clear.
