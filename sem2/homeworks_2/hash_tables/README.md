# sem2 / homeworks_2 / hash_tables

## Постановка задачи
1. Создать динамический массив из записей (в соответствии с вариантом), содержащий не менее 100 элементов. Для заполнения элементов массива использовать ДСЧ.
2. Предусмотреть сохранение массива в файл и загрузку массива из файла.
3. Предусмотреть возможность добавления и удаления элементов из массива (файла).

## Анализ задачи
### АНАЛИЗ ЛИНЕЙНОГО ПРОБИРОВАНИЯ

1. Ключ — строка даты, переводим в число и считаем хэш.
2. Идём по таблице от индекса хэша, сдвигаясь вправо до пустой ячейки.
3. Если дошли до конца — продолжаем с начала до исходного хэша.
4. Вставка/поиск линейно зависят от числа коллизий; при переполнении вставка невозможна.
### АНАЛИЗ МЕТОДА ЦЕПОЧЕК

1. Ключ — строка даты, переводим в число и считаем хэш.
2. Каждый индекс — список; вставка добавляет элемент в список корзины.
3. Поиск/удаление — линейный проход по списку корзины.
4. Коллизии считаются как длина списка перед вставкой.
