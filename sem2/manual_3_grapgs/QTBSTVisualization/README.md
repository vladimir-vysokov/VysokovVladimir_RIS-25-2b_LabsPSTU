## Постановка задачи
Задачи:Реализовать структуру данных «бинарное дерево поиска» с информационным полем типа double (вариант 25).Разработать алгоритмы:Вставки и удаления узловПоиска элемента по ключуПрямого, симметричного и обратного обходов дереваБалансировки дереваВертикальной и горизонтальной печати дереваСоздать графический интерфейс пользователя для взаимодействия с программой.Реализовать графическую визуализацию структуры дерева.Найти минимальный элемент в дереве (вариант 25).

## Анализ задачи
### АНАЛИЗ.

Визуализация бинарного дерева поиска обеспечивается через UiVertex (вершины) и QGraphicsLineItem (рёбра), где вершины наследуют графические элементы Qt, отображают числовой ключ типа double и поддерживают цветовую индикацию (красный — активный, синий — посещённый, зелёный — найденный/минимальный).
Класс BST реализует структуру данных «бинарное дерево поиска» на указателях (левый/правый ребёнок) с методами вставки, удаления, поиска, нахождения минимума, прямого/симметричного/обратного обходов и балансировки через сортировку ключей и рекурсивное построение.
GraphWorker выполняет пошаговую визуализацию операций над деревом, генерирует шаги анимации (подсветка пути при вставке/удалении/поиске/поиске минимума, последовательная подсветка узлов при обходах) и связывает модель BST с графическим представлением.
MainWindow принимает ввод ключа через соответствующее поле сверху, по нажатию кнопок запускает соответствующую операцию через GraphWorker, управляет сбросом анимации (Reset) и пошаговым воспроизведением (Next Step).
