# sem2 / manual_3_grapgs / QTGraphVisualization

## Постановка задачи
1. Реализовать структуру данных «взвешенный неориентированный граф» с использованием матрицы смежности
2. Разработать алгоритмы:
a) Обхода графа в ширину (BFS)
b) Обхода графа в глубину (DFS)
c) Поиска кратчайших путей от одной вершины до всех остальных (алгоритм Дейкстры)
d) Поиска кратчайших путей между всеми парами вершин (алгоритм Флойда-Уоршелла)
3. Создать графический интерфейс пользователя для взаимодействия с программой
4. Реализовать пошаговую визуализацию работы каждого алгоритма с возможностью просмотра промежуточных результатов
5. Обеспечить возможность редактирования графа (добавление/удаление вершин и рёбер, изменение весов)
6. Обеспечить возможность редактирования матрицы смежности

## Анализ задачи
### АНАЛИЗ.

Визуализация графа обеспечивается через UiVertex (вершины) и UiEdge (рёбра), которые наследуют графические элементы Qt и отвечают за отрисовку, цветовую индикацию и состояние рёбер.
Класс GraphWorker выполняет алгоритмы (BFS, DFS, Dijkstra, Floyd), управляет пошаговой визуализацией и связывает модель Graph с графическим представлением.
MatrixEditor отвечает за редактирование матрицы смежности через таблицу Qt и синхронизацию с Graph.
MainWindow выступает контроллером интерфейса, обрабатывает события кнопок и управляет запуском алгоритмов через GraphWorker.

## Результаты
BFS. Путь: 5→2→1, вернулись в 2→4. Синим помечены used vertex, красным – текущий шаг.
DFS: 5→2→1→3, вернулись 1→4
Dijkstra: 5→2→1
Floyd: Синим помечена 5-я vertex THROW, красным – 3 FROM, желтым – 4 TO. Новое значение [3][4] = сумме клеток, лежащих на пересечении красной+синей линии и желтой+синей.
