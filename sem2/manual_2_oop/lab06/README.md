# sem2 / manual_2_oop / lab06

## Постановка задачи
Класс-контейнер `Список` с ключевыми значениями типа `int`.

Требуется реализовать:
- `List::operator[]` для доступа по индексу;
- `List::operator()` для определения размера списка;
- `List::operator*` для умножения элементов списков `a[i] * b[i]`;
- `Iterator::operator+` для перехода вправо на `n` элементов.

## Анализ задачи
1. Создаём класс `BiNode` как узел списка.
2. Создаём класс `BiList` как двунаправленный список.
3. Создаём класс `Iterator` для перемещения по списку.

## Вопросы и ответы
1. Что такое абстрактный тип данных?
   АТД - это тип данных, определяемый только через операции, которые можно выполнять над объектами, без привязки к способу их представления.

2. Привести примеры абстракции через параметризацию.
   Абстракция через параметризацию может быть реализована так же, как и для функций.

3. Привести примеры абстракции через спецификацию.
   Абстракция через спецификацию достигается за счёт того, что операции представляются как часть типа.

4. Что такое контейнер?
   Контейнер - это набор однотипных элементов. Примеры: массив, список, стек, очередь.

5. Какие группы операций выделяют в контейнерах?
   - операции доступа к элементам;
   - операции добавления и удаления элементов;
   - операции поиска;
   - операции объединения контейнеров;
   - специальные операции, зависящие от вида контейнера.

6. Какие виды доступа к элементам контейнера существуют?
   - Прямой: доступ по индексу, например `a[10]`.
   - Ассоциативный: доступ по содержимому, например `a["word"]`.
   - Последовательный: перемещение от элемента к элементу контейнера.

7. Что такое итератор?
   Итератор - это объект, который обеспечивает последовательный доступ к элементам контейнера.

8. Каким образом может быть реализован итератор?
   Итератор можно реализовать как набор методов контейнера или как отдельный класс с интерфейсом, близким к указателю.

9. Каким образом можно организовать объединение контейнеров?
   Возможны разные варианты: сцепление, объединение множеств, пересечение множеств, разность, извлечение части элементов по диапазону итераторов.

10. Какой доступ к элементам предоставляет контейнер из пар «ключ-значение»?
    Это ассоциативный доступ, как у контейнера `map`.

11. Как называется контейнер, в котором вставка и удаление элементов выполняется на одном конце?
    Это стек.

12. Какой из объектов является контейнером?
    `int mas[100];`

13. Какой из объектов не является контейнером?
    `int mas;`

14. Контейнер реализован как динамический массив, а доступ к элементам идёт по индексу. Каким будет доступ?
    Прямым.

15. Контейнер реализован как линейный список. Каким будет доступ к элементам?
    Последовательным.
