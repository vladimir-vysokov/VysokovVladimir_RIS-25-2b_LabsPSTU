1. Что такое класс?
Класс - абстрактный пользовательский тип данных, представляющий собой модель реального объекта в виде данных (полей) и
функций (методов) для работы с ними. Вместе поля и методы называются элементами класса.

2. Что такое объект (экземпляр) класса?
Экземпляр класса - переменная (константа) в коде, имеющая тип класса.

3. Как называются поля класса?
Атрибуты

4. Как называются функции класса?
Методы

5. Для чего используются спецификаторы доступа?
Для сокрытия внутренних атрибутов и методов от пользователя.

6. Для чего используется спецификатор public?
Элементы класса, описанные в поле "public" доступны для использования вне класса при помощи операторов
subject.field (или subject->field, если subject - указатель)

7. Для чего используется спецификатор private?
Элементы класса, описанные в поле "public" не доступны для использования вне класса при помощи операторов
subject.field (или subject->field, если subject - указатель)

8. Если описание класса начинается со спецификатора class, то какой спецификатор
доступа будет использоваться по умолчанию?
private

9. Если описание класса начинается со спецификатора struct, то какой спецификатор
доступа будет использоваться по умолчанию?
public

10. Какой спецификатор доступа должен использоваться при описании интерфейса
класса? Почему?
В public, так как интерфейс подразумевает использование самого себя во вне класса.

11. Каким образом можно изменить значения атрибутов экземпляра класса?
При помощи операторов subject.field (или subject->field, если subject - указатель)

12. Каким образом можно получить значения атрибутов экземпляра класса?
При помощи операторов subject.field (или subject->field, если subject - указатель)

13. Класс описан следующим образом
struct Student
{
    string name;
    int group;
    ………
};
Объект класса определен следующим образом
Student *s=new Student;
Как можно обратиться к полю name объекта s?
s->name;
