# Лабораторная работа 0

## Тема

Оформление учебных материалов с использованием Markdown и базовых требований к представлению алгоритмов.

## Цель работы

Изучить основные элементы разметки Markdown и подготовить пример корректно оформленного документа, пригодного для размещения в репозитории.

## Основные сведения

Markdown позволяет оформлять текстовые документы в удобном для чтения виде. С его помощью можно создавать заголовки, списки, таблицы, ссылки, изображения, цитаты и блоки программного кода.

При описании алгоритмов также важно соблюдать единообразие оформления. Для блок-схем используется ГОСТ 19.701-90, который регламентирует условные обозначения элементов схем алгоритмов, программ, данных и систем.

## Элементы блок-схем

- начало и конец алгоритма;
- ввод исходных данных;
- вывод результатов;
- выполнение вычислительных действий;
- проверка условий;
- организация циклических процессов;
- вызов вспомогательных процедур и функций;
- хранение и обработка данных.

## Пример нумерованного списка

1. Определить цель документа.
2. Подготовить структуру разделов.
3. Добавить необходимые примеры.
4. Проверить корректность оформления.

## Пример вложенного списка

1. Раздел документа.
   1. Подраздел.
   2. Пояснение к подразделу.
2. Следующий раздел документа.

## Цитата

> Корректное оформление документации упрощает проверку, сопровождение и повторное использование учебных материалов.

## Таблица

| Элемент Markdown | Назначение |
|:-----------------|:-----------|
| Заголовок        | Разделение документа на смысловые части |
| Список           | Перечисление связанных пунктов |
| Таблица          | Представление структурированных данных |
| Блок кода        | Демонстрация программного фрагмента |
| Ссылка           | Переход к внешнему или внутреннему ресурсу |

## Экранирование символов

Некоторые служебные символы Markdown можно вывести как обычный текст с помощью обратной косой черты:

```text
\#
\*
\[
```
